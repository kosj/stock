# 저장 추천·종가 실자료 진단

이 자료에서는 추천 전략의 우위나 이번 수정의 수익 개선을 확인하지 못했다.
과거 저장된 Top5는 KOSPI보다 평균적으로 높았지만, 초과수익의 HAC t 값이
모든 측정 기간에서 0.34 미만이다. 비용을 반영하지 않은 값이며 신규 코드의
성과 측정도 아니다. 이 결과만으로 가중치나 손절 값을 변경하지 않는다.

## 데이터와 계산

- 읽기 전용으로 추출한 추천 **10,234행 / 120개 기준일**: 2026-05-29~2026-10-16.
- 저장 종가 **114,422행**, KOSPI 관측 **1,260거래일**: 2021-08-17~2026-10-16.
  가격의 결측/0/음수/비유한 값과 티커·날짜 중복은 이번 추출본에서 0개였다.
- 별도 읽기 전용 확인에서 완료 배치(`recommendation_batches`)는 **0건**이었다.
  아래는 기존 추천 행의 품질 진단이다. 미검증 배치를 자동매매에 승격하지 않았다.
- 저장 국내 종가의 날짜 합집합으로 공통 세션을 구성했다. benchmark 날짜 수와 일치했다.
  진입은 기준일 이후 첫 관측 세션 **종가**, 청산은 그로부터 H세션 뒤 종가다.
  종목/벤치마크의 양끝 날짜 가격이 정확히 없으면 제외하고 보간하지 않는다.
- `created_at`이 진입일 15:30 KST 이후인 행은 제외한다. 실제 추출본의 해당 제외는 0행,
  기록 시각 미기재도 0행이었다. 행 생성 시각이 완료 배치 발행 시각을 증명하지는 않는다.
- 주말 기준일이 21개 존재한다. 여러 기준일이 같은 진입 세션에 대응하므로 먼저
  같은 진입일별 코호트 지표를 평균한 뒤 전체 평균과 Newey-West t를 계산했다.
  주말 추천을 독립된 거래일로 중복 계산하지 않는다.
- Top5 지표는 저장 순위 1~5가 유일하고 모두 평가 가능한 코호트만 사용한다.
  IC는 최소 5종목이며 동률은 평균 순위로 계산한다. NW lag는 H로 설정했다.

## 결과

단위: 수익/초과수익은 **% 또는 %p**. 각 열은 중첩된 코호트의 평균이다.
누적 수익률이나 리밸런싱 계좌 성과로 합산·복리 계산하면 안 된다.

| H세션 | 완전 Top5 코호트 / 진입일 | 행 매칭률 | Top5 평균 수익 | KOSPI 대비 평균 초과 | 초과수익 NW t | 저장 순위 IC / NW t |
|---:|---:|---:|---:|---:|---:|---:|
| 1 | 115 / 90 | 97.90% | -0.396% | +0.028%p | 0.090 | 0.0433 / 1.609 |
| 5 | 110 / 86 | 93.50% | -1.555% | +0.158%p | 0.148 | 0.0096 / 0.223 |
| 10 | 104 / 81 | 88.23% | -2.651% | +0.130%p | 0.068 | 0.0365 / 0.987 |
| 20 | 92 / 71 | 77.67% | -4.544% | +1.120%p | 0.332 | 0.0170 / 0.385 |

Top5와 **같은 코호트의 평가 가능한 전체 저장 종목 평균**을 비교한 차이는
H=1/5/10/20에서 각각 **-0.143 / -0.593 / -1.023 / -1.994%p**였다.
그 차이의 NW t도 -0.894 / -1.014 / -0.946 / -1.003으로 불확실하다.
전체 저장 종목은 당시 투자 가능 전체 시장과 같지 않으며 현재 유니버스의 영향을 받는다.

원시 예측 값(`predicted_return_7d`)의 IC는 같은 순서로
**0.0094 / -0.0032 / -0.0292 / -0.0552**였다. 이 레거시 필드는 실제 10세션 알파에
재사용되므로 1/5/20세션 결과는 기간 민감도 진단이다. 해당 기간의 수익률 보정 성능으로
해석하지 않는다. 저장 순위와 원시 예측은 혼합 점수/순위 정책 때문에 다른 지표다.

각 기간에서 정확한 종가가 없는 추천 **35행**을 제외했다.
미성숙 또는 이후 가격 미확보로 **180 / 630 / 1,170 / 2,250행**을 제외했다.
평가 성숙 코호트 중 Top5 순위/가격이 완전하지 않은 코호트는 각 기간 **3개**였다.
제외 행을 수익률 0으로 채우거나 부족한 Top5를 나머지 종목으로 대체하지 않았다.

## 해석 한계와 다음 작업

- 전체 기간이 짧고 라벨이 겹친다. 20세션 진입일 71개는 독립된 71회 베팅이 아니다.
  대략 비중첩 3개 구간 정도의 길이이며, NW t 역시 안정적인 유의성 보장이 아니다.
  여러 기간/지표를 함께 확인한 다중검정도 고려해야 한다.
- 과거 생성 코드/모델/유니버스가 섞여 있다. 마지막 추천일은 이번 수정 전이다.
  이번 변경의 전후 성과 차이를 이 데이터로 입증할 수 없다.
- 조정 종가에 사후 기업행위 수정이 반영되었을 수 있다. 과거 수급·재무·뉴스·감성,
  당시 유니버스/상장폐지 및 완료 배치 발행 원본이 모두 고정되어 있지 않다.
- 09:12 실제 관측 가격, 거래비용·세금·슬리피지·체결 용량·장중 손절을 반영하지 않았다.
  진입/청산 종가와 벤치마크의 시각 일치도 실제 체결 가능성을 뜻하지 않는다.
- 우선 완료 배치와 입력 버전을 누적하고, 같은 당시 관측 가능한 입력으로 기존/신규
  전략을 고정한 walk-forward 및 공통 거래 엔진 리플레이를 수행한다.
  그 후에 별도 검증 구간에서 보정·가중치·손절 정책 변경 여부를 결정한다.

## 재현 및 회귀 검증

원시 추출본은 개인 계좌/주문 정보를 포함하지 않는 시장 데이터와 추천 데이터였다.
전체 집계와 일별 지표, 입력 파일 SHA-256은 인접한
`recommendation-diagnostics-20261020.json`에 기록했다.

```bash
python3 scripts/recommendation_diagnostics.py \
  --recommendations /tmp/stock-recommendations-export.json \
  --prices /tmp/stock-prices-export.json \
  --output docs/recommendation-diagnostics-20261020.json \
  --completed-batches-count 0
python3 scripts/test_recommendation_diagnostics.py
```

진단기는 파일만 읽고 네트워크/학습/DB 쓰기를 실행하지 않는다. 신규 테스트 5개로
진입일·성숙도, 정확한 가격, 벤치마크 결측 시 기간 밀림 방지, 중복/늦은 생성 거부,
동일 진입일 가중치, JSON 형식과 상수 IC 처리를 확인했다.
기존 `backtest_recommendations.py`에서도 중첩 알파 합계를 누적 수익률처럼 출력하던
부분을 제거하고 정확한 벤치마크 날짜를 요구하도록 수정했다.
