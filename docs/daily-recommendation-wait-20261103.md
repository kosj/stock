# 데일리 모의거래 추천 대기 — 2026-11-03

## 확인 및 수정

11월 2일 daily job 두 계정이 각각 3회 시도 후 실패했다. 하나는 10월 23일 완료 추천이
만료돼 매수·순위 청산을 보류했으나 손절 검사는 완료된 경우다. 다른 하나는 KIS 설정이
저장돼 있지 않고 유효한 대체 시세도 없어 보유 5종목의 위험 검사를 완료하지 못했다.
운영 조회는 설정 존재 여부만 확인했으며 암호문이나 키를 읽지 않았다. 설정이 저장된
다른 계정의 키가 유효한지, 공급자에 연결되는지는 이 조회로 증명하지 않는다.

- 빈 추천 또는 구조적으로 완전한 만료·당일 배치는 손절 검사 완료 시
  `waiting_recommendation`과 `notice`를 기록한다. 신규 매수·순위 청산은 보류한다.
- 불완전·중복·잘못된 가격·미래일·잘못된 날짜, DB 조회 오류는 대기로 숨기지 않는다.
  완료 배치가 있는데 종목 조회가 실패하거나 비어 있는 경우도 장애다.
- 시세·주문·성과 관측 저장 오류는 기존 실패 처리를 유지한다. 위험 검사 미완료도
  daily queue의 완료로 처리하지 않는다.
- 완료된 대기는 기존 일일 job의 done으로 남기고 재시도하지 않는다. API는 당일 done 중
  대기 건수를 별도 반환하고 Actions 로그·성공 summary에서 추천 대기를 표시한다.
  기존 실패 job을 소급 완료로 바꾸거나 재시도 횟수를 초기화하지 않는다.

## 계정 설정과 검증 한계

시세 장애 계정의 소유자가 앱의 증권사 설정에서 본인 KIS AppKey/AppSecret과 사용 환경을
등록해야 한다. 키를 대화에 붙이거나 다른 계정의 키를 복제하지 않는다. 저장 후 정규장에서
실제 거래 시각·신선도 및 손절 검사 완료를 확인해야 한다. 장외 skipped 성공은 이 검증이
아니다. 조회용 키 등록으로 실거래 주문을 활성화하지 않는다.

운영 DB·자동매매·추천을 검증용으로 변경하거나 거래 cron을 호출하지 않았다. 테스트는
가짜 HTTP와 격리 DB를 사용한다. 주간 모델의 품질 기준과 정상 보류는 유지한다.
